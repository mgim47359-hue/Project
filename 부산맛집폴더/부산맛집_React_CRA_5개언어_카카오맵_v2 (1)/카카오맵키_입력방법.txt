카카오맵 키 입력 방법

1. src/config.js 파일을 엽니다.
2. KAKAO_MAP_JAVASCRIPT_KEY 값을 찾습니다.
3. "여기에_카카오맵_JAVASCRIPT_KEY_입력" 부분을 발급받은 JavaScript 키로 교체합니다.

예시
KAKAO_MAP_JAVASCRIPT_KEY: "발급받은_JavaScript_키"

주의
- REST API 키가 아닌 JavaScript 키를 사용합니다.
- 카카오 개발자 콘솔의 플랫폼 > Web에 다음 주소를 등록합니다.
  http://localhost:3000
  https://yshop.github.io
- 키 변경 후 npm run build 또는 npm run deploy를 다시 실행합니다.
