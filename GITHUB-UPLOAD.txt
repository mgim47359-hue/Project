[GitHub Pages 업로드 방법]

1. 기존 GitHub 저장소의 이전 slider 파일과 섞지 말고 이번 폴더의 파일로 교체합니다.
2. index.html / css / js / imges 폴더를 저장소의 같은 위치에 업로드합니다.
3. 이미지 파일명은 대소문자까지 정확히 맞춥니다.
4. 배포 후 브라우저에서 Ctrl + F5로 강력 새로고침합니다.

이번 수정본 핵심
- 왼쪽 버튼: productSwiper.slidePrev() 직접 호출
- 오른쪽 버튼: productSwiper.slideNext() 직접 호출
- 오른쪽 버튼 z-index / pointer-events 보강
- 3초 자동재생 유지
- 한 화면 3개, 한 번에 1개씩 이동
- 첨부한 윤조아이세럼 / 여윤팩 / 순행클렌징폼 이미지를 banner04~06에 반영
