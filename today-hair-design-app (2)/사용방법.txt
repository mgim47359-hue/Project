오늘의 헤어디자인 앱 실행 방법

1. 준비물
- Node.js 20 이상
- VS Code

2. 설치 및 실행
VS Code에서 이 폴더를 연 뒤 터미널에 아래 명령어를 순서대로 입력하세요.

npm install
npm run dev

터미널에 표시되는 localhost 주소를 브라우저에서 열면 됩니다.

3. 카카오맵 키 입력
- 앱 화면 아래의 '카카오 JavaScript 키' 입력란에 발급받은 JavaScript 키를 입력합니다.
- 카카오 개발자 콘솔의 플랫폼 > Web에 실행 주소를 등록합니다.
- 로컬 실행 주소 예시: http://localhost:3000
- 배포 후에는 실제 배포 주소도 등록해야 합니다.

4. 주요 기능
- 두피 상태별 헤어 및 관리 추천
- 서비스, 인사, 청결, 시술 정확도, 두피 맞춤 관리, 전체 만족도 별점
