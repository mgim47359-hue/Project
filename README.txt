[설화수 추천 Banner Slider]

1. index.html을 더블클릭해서 실행합니다.
2. 실제 배너 이미지는 imges 폴더 안의 아래 파일만 교체하면 됩니다.
   - banner01.png
   - banner02.png
   - banner03.png
   - banner04.png
   - banner05.png
   - banner06.png
3. 일시정지/재생 아이콘도 교체할 수 있습니다.
   - icon-pause.png
   - icon-play.png
4. Swiper 11 CDN을 사용합니다.
   인터넷 연결이 없는 경우에도 script.js 안의 폴백 기능으로 기본 슬라이드는 동작합니다.
5. 주요 코드에는 요청대로 주석을 기입해 두었습니다.

주요 설정
- section 전체 높이: 950px
- inner: 1440px
- slide 영역 높이: 600px
- 한 화면: 3개
- 전체: 6개
- 이동 단위: 1개
- autoplay: 3000ms
- 제목: 28px
- 카드 텍스트: 18px
